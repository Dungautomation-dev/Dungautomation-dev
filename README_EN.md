### 👨‍💻 About Me

- ⚡ **Core Expertise**: Desktop software development on **C# .NET**, crafting modern, ultra-lightweight, 100% Native **WPF (Windows Presentation Foundation)** user interfaces with zero unnecessary dependencies and optimal execution speed.
- 📐 **CAD Automation**: Engineering specialized DLL plugins for **AutoCAD** (.NET API / ObjectARX) that streamline drafting and accelerate design workflows by 5x - 10x.
- 🔒 **Security & Intelligence**: Implementing anti-reverse engineering code obfuscation (**ConfuserEx**) and optical character recognition (**Tesseract OCR**).
- 💡 **Core Philosophy**: *"Clean code, optimal performance, refined user experience, and automating every repetitive process."*
